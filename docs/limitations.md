# Demo boundaries

Request intake, declared evidence, deterministic risk and audit history are available through the local API. Complete submissions stop at UNDER_REVIEW. The Angular dashboard still shows the bootstrap shell. Human review, AI recommendations and Jira dispatch belong to later phases.

The dashboard uses synthetic data only. Demo personas provide no access control. Bind the API to loopback and keep the dashboard on the same machine.

Integration modes describe settings. The application currently makes no provider calls. Evidence records are declarations by the requester, and the sample risk rubric is illustrative. Independent document verification and compliance decisions are outside the demo.

A future live Jira create can have an ambiguous outcome. The design records uncertainty and searches for a request marker before any further create attempt. See [the architecture](architecture.md).
