## Ownership rules

| If you need to… | It goes in… | Never in… |
|---|---|---|
| change when a status may change | `domain/transitions.py` | API handlers, graph nodes |
| change the score or required evidence | `domain/rules.py` | prompts, frontend |
| call the LLM | `agents/llm_adapter.py` | services, API |
| call Jira | `integration/jira_client.py` via `dispatcher.py` | graph nodes, API handlers |
| write an audit event | `persistence/repositories.py` in the same transaction as the change | a separate later call |
| define an API type on the frontend | generated by `npm run gen:api` | hand-written interfaces |
